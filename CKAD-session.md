# 📝 CKAD Session

Combined session start checklist, append-only log, and end-of-session summary template.

## 🚦 Session start checklist

Use this at the beginning of every session.

1. Review the latest session summary.
2. Review the latest session log.
3. Review the topic checklist.
4. Review the relevant reference notes or answer key.
5. State the current date.
6. State the session number.
7. State the days until exam, if known.
8. State the active weak spots.
9. State the plan for this session.
10. Begin with the planned drill.

### ⚠️ Do not
- Skip the review step.
- Start with a generic quiz.
- Introduce new topics without a reason.
- Ask for confirmation at the end of the checklist.
