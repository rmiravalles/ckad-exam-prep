# 📚 CKAD Sources

Use these sources to verify drills and answer keys. Prefer the official Kubernetes documentation when local examples do not cover a behavior or field.

| Source | Use for |
| --- | --- |
| [CKAD certification overview](https://training.linuxfoundation.org/certification/certified-kubernetes-application-developer-ckad/) | Current exam scope, registration details, and official candidate information. |
| [Kubernetes documentation](https://kubernetes.io/docs/) | Conceptual explanations and task guides. |
| [Kubernetes API reference](https://kubernetes.io/docs/reference/kubernetes-api/) | Exact resource fields and API shapes. |
| [kubectl reference](https://kubernetes.io/docs/reference/kubectl/) | Command syntax and options. |
| [kubectl cheat sheet](https://kubernetes.io/docs/reference/kubectl/cheatsheet/) | Common command patterns and shell workflows. |
| [Kubernetes task guides](https://kubernetes.io/docs/tasks/) | Applied examples for configuration, workloads, networking, storage, and debugging. |
